# Тести бекенду

## Запуск

З папки `trip_backend`:

    venv/Scripts/python -m pytest tests -v

Перед запуском має бути піднята БД:

    docker compose up -d db

Окремі групи:

    venv/Scripts/python -m pytest tests/auth tests/trips -v

## Структура

- `conftest.py` — спільні фікстури (`client`, `fresh_db`, `auth_headers`) та почистка БД перед кожним тестом;
- `auth/`       — автентифікація, токени й сесії (Блок 1): реєстрація/логін/logout, профіль, видалення акаунта;
- `trips/`      — життєвий цикл поїздок: архів (і read-only режим), інвайти та їх термін дії, учасники, передача власника, пошук/пагінація, валідація PATCH;
- `items/`      — речі: CRUD, права доступу (автор/організатор), assign та кількість, перенесення між категоріями, наслідування речей;
- `categories/` — категорії: права доступу, унікальність назв, видалення з перенесенням речей (`move_to`);
- `activity/`   — стрічка активності (Activity feed);
- `perf/`       — Блок 2: продуктивність після `expire_on_commit=False`, каскадні видалення, конкурентні запити (гонки), rate-limit, healthz/CORS.
